The product is now IsnadiBot everywhere: the `isnadi` command, `ISNADI_*` environment variables, `~/.isnadi`, and the `isnadi://` desktop scheme. Existing data moves over on first launch, including the server database, the app's stored settings and themes, saved connections, in-app browser sessions, and old chat blocks and archives. The old `AKERU_*` environment variables still work. Product feedback is off until you set your own endpoint.
